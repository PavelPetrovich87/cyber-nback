# Cloud Infrastructure Skill (Template)

## When to Use
- Deployment plans (API hosting, DB, storage)
- CI/CD workflows
- Environment separation (dev/staging/prod)

## Patterns
- Keep secrets in CI/hosting secret stores, not git
- Prefer small, incremental infra steps for MVP
- Document required env vars in `backend/.env.example` and `frontend/.env.example` (if applicable)
